# Flow titip harian

## Rumah tangga (3 ketuk)

1. Buka `HomeList` → pilih vendor keliling hari ini (jadwal + ETA).
2. Pilih item titipan → konfirmasi jadwal titip.
3. Bayar/konfirmasi → lacak status (dibuat → diterima → diantar → selesai).

Langganan: `HomeSubscription` → pilih pola harian/mingguan/bulanan → aktif.

## Vendor

1. Buka `VendorCatalog` → atur katalog + stok hari ini.
2. Atur jadwal keliling (rute + jam).
3. `VendorOrders` → terima/tolak pesanan masuk → tandai diantar/selesai.

## Aturan

- Batal hanya sebelum status `diantar`.
- Notifikasi setiap perubahan status.
